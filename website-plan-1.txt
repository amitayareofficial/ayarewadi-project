────────────────────────────────────────────────────────────────────────────────
1. PROJECT OVERVIEW
────────────────────────────────────────────────────────────────────────────────

A bilingual (मराठी / English) village information portal for Ayarewadi village,
Sindhudurg district, Maharashtra, India.

Purpose:
  - Central information hub for village residents
  - Emergency contacts and nearby hospitals
  - Events, festivals, and village news
  - Member portal (family tree + village budget — login required)
  - Photo gallery
  - Blog / village news articles
  - Admin panel to manage all content from the browser
  - WhatsApp community link

Domain: ayarewadi.in


────────────────────────────────────────────────────────────────────────────────
2. TECH STACK
────────────────────────────────────────────────────────────────────────────────

CLIENT (Frontend)
  Framework    : React 19 (Vite 8 bundler)
  Styling      : Pure CSS (custom design system) + Tailwind CSS v4 (utility layer)
  HTTP         : axios
  Markdown     : react-markdown  (for Blog post rendering)
  Animations   : framer-motion (installed, available for use)
  Icons        : lucide-react (installed, available)
  Path alias   : @ → ./src

SERVER (Backend)
  Runtime      : Node.js
  Framework    : Express 5
  Database     : PostgreSQL (via `pg` pool)
  Auth         : JWT (jsonwebtoken) + bcrypt (password hashing)
  File Upload  : multer (memory storage) → Cloudinary
  Image CDN    : Cloudinary (village photos stored and served from there)
  Env Vars     : dotenv

DEPLOYMENT
  Client  → Vercel  (cd client && vercel --prod)
  Server  → Render  (https://ayarewadi-project.onrender.com)
  DB      → PostgreSQL on Render (DATABASE_URL in server/.env)

BUILD COMMAND (client)
  npm run build   → runs vite build → outputs to client/dist/

4. NAVIGATION ARCHITECTURE (Single-Page App)
────────────────────────────────────────────────────────────────────────────────

No React Router is used. Navigation is state-based:

  const [section, setSection] = useState("home");

  Sections:  home | emergency | portal | gallery | events | blog | admin

  nav(s) function:
    - setSection(s)
    - setMenuOpen(false)
    - window.scrollTo({ top: 0, behavior: "smooth" })

The navbar conditionally applies the "scrolled" class at window.scrollY > 60,
which switches it from transparent/white-text to white/dark-text.

5. DATABASE SCHEMA (PostgreSQL)
────────────────────────────────────────────────────────────────────────────────

TABLE: admins
  id          SERIAL PRIMARY KEY
  username    TEXT NOT NULL UNIQUE
  password    TEXT NOT NULL          ← bcrypt hashed
  created_at  TIMESTAMP DEFAULT NOW()

TABLE: events
  id          SERIAL PRIMARY KEY
  title       TEXT NOT NULL
  description TEXT
  date        DATE
  category    TEXT DEFAULT 'General'
  is_marquee  BOOLEAN DEFAULT false
  created_at  TIMESTAMP DEFAULT NOW()

TABLE: announcements
  id          SERIAL PRIMARY KEY
  text        TEXT NOT NULL
  active      BOOLEAN DEFAULT true
  created_at  TIMESTAMP DEFAULT NOW()

TABLE: gallery
  id             SERIAL PRIMARY KEY
  url            TEXT NOT NULL        ← Cloudinary full URL
  thumbnail_url  TEXT                 ← Cloudinary URL with /upload/w_400/
  caption        TEXT
  category       TEXT
  uploaded_at    TIMESTAMP DEFAULT NOW()

TABLE: emergency
  id                 SERIAL PRIMARY KEY
  name               TEXT NOT NULL
  type               TEXT               ← Hospital | Police | School | Government
  phone              TEXT
  address            TEXT
  maps_url           TEXT
  emergency_contact  TEXT

TABLE: budget
  id          SERIAL PRIMARY KEY
  description TEXT NOT NULL
  type        TEXT                     ← income | expense
  amount      NUMERIC
  month       TEXT
  created_at  TIMESTAMP DEFAULT NOW()

TABLE: blog_posts
  id           SERIAL PRIMARY KEY
  title        TEXT NOT NULL
  slug         TEXT UNIQUE             ← auto-generated from title
  content      TEXT                    ← Markdown content
  category     TEXT DEFAULT 'Village News'
  cover_image  TEXT                    ← URL (optional)
  published    BOOLEAN DEFAULT false
  created_at   TIMESTAMP DEFAULT NOW()
  updated_at   TIMESTAMP DEFAULT NOW()

TABLE: members
  id          SERIAL PRIMARY KEY
  member_id   TEXT UNIQUE              ← e.g. AYR001
  password    TEXT                     ← plain text (simple village use)
  household_name TEXT
  house_no    TEXT

TABLE: family
  id          SERIAL PRIMARY KEY
  member_id   TEXT                     ← FK to members.member_id
  name        TEXT
  role        TEXT                     ← Head | Wife | Son | Daughter etc.
  phone       TEXT

6. API ENDPOINTS (server/index.js)
────────────────────────────────────────────────────────────────────────────────

BASE URL: https://ayarewadi-project.onrender.com

PUBLIC (no auth required):
  GET  /                          → Health check
  GET  /events                    → All events (newest first)
  GET  /announcements             → Active announcements only
  GET  /gallery                   → All photos (optional ?category=X)
  GET  /emergency                 → All emergency contacts
  GET  /budget                    → All budget entries
  GET  /blog                      → Published blog posts only
  POST /login                     → Member login {member_id, password}
  GET  /family/:member_id         → Family members for a member

ADMIN (requires JWT Bearer token):
  POST   /admin/login             → {username, password} → returns {token}
  POST   /events                  → Create event
  PUT    /events/:id              → Update event
  DELETE /events/:id              → Delete event
  POST   /announcements           → Create announcement
  DELETE /announcements/:id       → Delete announcement
  POST   /gallery/upload          → Upload photo (multipart/form-data, field: "photo")
  DELETE /gallery/:id             → Delete photo
  POST   /emergency               → Create emergency contact
  PUT    /emergency/:id           → Update emergency contact
  DELETE /emergency/:id           → Delete emergency contact
  POST   /budget                  → Create budget entry
  DELETE /budget/:id              → Delete budget entry
  GET    /blog/all                → All posts (incl. unpublished)
  POST   /blog                    → Create post
  PUT    /blog/:id                → Update post
  DELETE /blog/:id                → Delete post

AUTH FLOW:
  Admin logs in → POST /admin/login → receives JWT
  JWT stored in localStorage as "admin_token"
  All admin requests send: Authorization: Bearer <token>
  Token expires: 7 days

8. BILINGUAL SYSTEM (मराठी / English)
────────────────────────────────────────────────────────────────────────────────

All user-facing text lives in a LANG object at top of App.jsx:

  const LANG = {
    en: { nav, hero, marquee, services, vd, rt, initiatives,
          festivals, eventsPreview, team, join, footer,
          emergency, portal, gallery, events },
    mr: { ... same keys, Marathi values ... }
  }

State: const [lang, setLang] = useState("mr");   ← defaults to मराठी
Language toggle buttons sit in the navbar (English | मराठी).

Each section reads:  const t = LANG[lang].sectionKey;
Then uses:           {t.title}, {t.subtitle} etc.

Hard-coded text that doesn't change (team member names, addresses, phone numbers)
stays in English in both language modes.

Rule: Always write मराठी in Devanagari script, never romanized "marathi".

10. KEY CSS COMPONENTS & PATTERNS
────────────────────────────────────────────────────────────────────────────────

EYEBROW LABEL (.eyebrow)
  - Small uppercase label above section headings
  - Has a short horizontal red bar via ::before pseudo-element
  - Used universally across all sections for visual consistency

SECTION HEADERS (.sec-header)
  - text-align: center  (all sections)
  - margin-bottom: 36px
  - Contains an .eyebrow span + h2

BENTO GRID (.svc-bento)
  - 2×2 grid, each card 320px tall
  - Cards are background-image covers with dark overlay
  - Glass panel at bottom (backdrop-filter blur)
  - Green tag badge at top-left of each card

GLASSMORPHISM CARDS (.team-card)
  - background: rgba(255,255,255,0.055)
  - backdrop-filter: blur(28px)
  - Used for team member cards on dark background

MARQUEE ANIMATION
  - @keyframes scroll-left: translateX(0) → translateX(-50%)
  - Items doubled in JS ([...arr, ...arr]) for seamless loop
  - Pauses on hover
  - Used in: hero bottom bar, team section top banner

SCROLLING MARQUEE AT HERO BOTTOM (.hero-marquee-bar)
  - position: absolute, bottom: 0, z-index: 4
  - Semi-transparent dark bg with backdrop blur
  - Shows slogans in the active language

NAVBAR BEHAVIOR
  - Transparent with white text when at top of hero
  - White bg with dark text once scrolled > 60px (or on non-home section)
  - Hamburger menu on mobile (< 768px)
  - Language toggle buttons (pill style) next to brand name

INFO CARD (.info-card)
  - White card with 3px left accent border (red)
  - Used for budget, notice board, other helplines
  - Adjacent cards use CSS sibling selector for spacing:
    .info-card + .info-card { margin-top: 20px }

EVENT CARDS (.event-card)
  - 3-col grid on desktop, 2-col tablet, 1-col mobile
  - 4px top border accent, white bg
